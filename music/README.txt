INSTRUCCIONES PARA AGREGAR MÚSICA DE FONDO:

1. Coloca tu archivo de música favorita en esta carpeta con el nombre: background.mp3
2. Formatos aceptados: .mp3, .wav, .ogg
3. La música se reproducirá automáticamente después del login
4. Se pausará automáticamente cuando se reproduzcan los videos
5. Se reanudará cuando los videos se pausen o terminen
6. Volumen configurado al 30% para no ser muy intrusivo

Sugerencia: Puedes usar música suave y romántica para el tema del jardín de flores.
